Dummy REST API Simulator & Interactive Console

Every request uses a simulated service worker/interceptor directly inside this page. You can trigger API calls with UI buttons, or automate them using Playwright's page.request.post() or route interception.

Available Endpoints

POST /api/login

Authenticate with valid credentials to receive a JWT access token.

POST /api/login (Bad Pwd)

Test negative response with invalid credentials (401 Unauthorized).

GET /api/products

Retrieve catalog JSON list of all available inventory items.

POST /api/logout

Invalidate active token and session cookie.
